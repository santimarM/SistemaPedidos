## Introducción

Este proyecto tiene como objetivo desarrollar el diseño orientado a objetos de un sistema de gestión de pedidos para Sabor Kiosco, un pequeño local gastronómico. La solución busca digitalizar la toma de pedidos, su seguimiento entre mostrador y cocina, y su entrega, reduciendo errores operativos y mejorando la coordinación del negocio.
